Horror Game - 2026

Unreal Engine 5 - (Work in Progress)

I am currently developing this project alongside my studies in South Korea to keep my technical skills sharp, experiment with new engine features, and deepen my experience with Unreal Engine 5. You can view a video preview of the current build as well as an Excel Technical Breakdown detailing the systems implemented so far.

Concept & Gameplay: An atmospheric survival horror game in which the player takes on the role of a technician tasked with restoring power to an abandoned warehouse. The core gameplay loop balances objective-driven repairs with tactical survival: players must search for fuses to activate electrical traps while evading a persistent, AI-driven animatronic. Featuring environmental storytelling and randomized tool spawns to maintain tension and replayability, the experience culminates in a final confrontation once all systems are restored.

Unreal Engine Experiments - 2024 / 2025

Personal and Professional Projects – C++ / Blueprints - Gameplay Camera System - PCG - Ink

After building solid game development fundamentals with Unity, I transitioned to Unreal Engine 5 to explore more advanced workflows and real-time capabilities—a versatility also widely leveraged in the film and VFX industries. Below is an overview of the projects I developed across professional internships and personal experiments:

Runtime Gameplay Testing Tool (Internship):

Developed a configurable tool enabling game designers to tweak and test gameplay mechanics directly at runtime, featuring:

  • Dynamic camera behaviors built with the new Gameplay Camera System.
  • A customizable player controller with full movement and orientation settings.
  • A combat system equipped with hitboxes, enemy spawners, and AI behaviors.
  • An in-game user interface to manage presets and apply live adjustments.

  • One-Day Parkour Challenge: Built a fast-paced prototype focused on physics interactions and a parkour-style controller where the objective is to destroy all targets across the map.

Unreal Engine continues to inspire me through its depth and flexibility, and I remain committed to exploring its full potential.

Weather Web Application - 2024

NodeJS, REST API, SQLite, Twig, AJAX

This project involved developing a full-stack weather web application providing real-time meteorological data and forecasts for selected cities. The technical stack combines Node.js, the Locationforecast 2.0 REST API, an SQLite database, and the Twig templating engine.

Key Implemented Features:

  • Searching for cities directly from the local database.
  • Selecting a city to view detailed meteorological conditions.
  • Fetching and displaying real-time weather data and forecasts via external API requests.

Special attention was given to user experience and performance optimization by leveraging AJAX requests to update weather data dynamically without reloading the entire page. Development followed a structured Git workflow on GitHub, with each feature isolated on dedicated branches.

Database Management Software - 2024

Object-Oriented Architecture - C++/CLI (.NET) - SQL & MCD

During my engineering studies, I focused on mastering object-oriented architecture to design maintainable, scalable, and modular applications. By structuring code around objects that encapsulate data and expose dedicated services, this paradigm improves code reusability and simplifies complex updates.

Developed in C++/CLI (.NET) to combine low-level object-oriented principles with a complete graphical interface, this desktop application enables company staff to manage relational records based on user roles (for instance, allowing a "Customer Manager" profile to view, add, edit, or delete client entries). We also designed the underlying database from scratch—starting from a Conceptual Data Model (MCD)—and iteratively refined it to align with client specifications while ensuring data integrity and optimization.

Embedded Weather Station - 2024

Arduino Uno - Embedded C++ - SysML - Sensors, GPS & Interrupts

(Video demonstration currently unavailable — full details available in the presentation below.)

As part of my engineering curriculum, I designed and built an embedded weather station powered by an Arduino Uno, featuring multiple acquisition modes and local data logging on an SD card.

Hardware & Software Architecture:

  • Hardware Integration: Interfaced four environmental sensors (light, temperature, humidity, and atmospheric pressure) alongside a GPS module, an status LED, and two push-buttons.
  • System Engineering & Embedded C++: Conducted a preliminary SysML analysis to define the system architecture before implementing the C++ firmware over three weeks, focusing on serial communication, hardware interrupt handling, and strict memory optimization tailored to the Arduino Uno's limited resources.
